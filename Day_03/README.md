# Day 3 — Python Data Structures & File Handling

**Date:** 7 October 2026  
**Program:** AI/ML Internship

## Overview

Day 3 focused on Python data structures and file handling. The task involved learning how lists, tuples, dictionaries, and sets work, followed by building a **Student Record Management System** that stores and retrieves student information using a text file.

## Learning Objectives

- Understand Python's built-in data structures.
- Perform basic operations on lists, tuples, dictionaries, and sets.
- Learn how to read from and write to text files.
- Build a menu-driven application using functions and loops.
- Implement basic record management with persistent file storage.

## Topics Covered

### 1. Lists

Learned how to work with ordered, mutable collections.

- Accessing elements using indexes.
- Adding elements using `append()`.
- Removing elements using `remove()`.
- Updating existing elements.
- Counting elements using `len()`.

### 2. Tuples

Explored ordered, immutable collections.

- Accessing tuple elements using indexes.
- Understanding immutability.
- Using tuples to store related values that should remain unchanged.

### 3. Dictionaries

Practiced storing structured information using key-value pairs.

- Creating dictionaries.
- Accessing values through keys.
- Representing student information using fields such as ID, name, and marks.

### 4. Sets

Learned how sets store unique elements and support mathematical set operations.

- Removing duplicate values automatically.
- Union of two sets.
- Intersection of two sets.
- Difference between two sets.

### 5. File Handling

Practiced working with text files to store and retrieve records.

- Reading records using file operations.
- Appending new records to a file.
- Rewriting a file when deleting records.
- Handling missing files using `try` and `except FileNotFoundError`.

## Project: Student Record Management System

Developed a menu-driven Python application that manages student records using a text file named `students.txt`.

### Features

- **Add Student:** Accepts student ID, name, age, course, and marks, then saves the record to a file.
- **View All Students:** Reads and displays the stored student records.
- **Search Student:** Finds and displays a student record using the student ID.
- **Delete Student:** Removes a student record based on the supplied ID.
- **Exit:** Terminates the program through the menu.

### Concepts Implemented

- Functions for modular programming.
- `while` loops for continuous menu interaction.
- Conditional statements for menu selection.
- File handling for persistent storage.
- String operations using `split()` and `strip()`.
- Exception handling for missing files.

## Key Learnings

- Choosing appropriate data structures for different types of information.
- Understanding the differences between mutable and immutable collections.
- Using sets to identify unique values and perform set operations.
- Reading, appending, and rewriting text files.
- Building a menu-driven application using functions and conditional logic.
- Maintaining records beyond a single program execution through file storage.

Day 3 strengthened Python programming skills by combining data structures, functions, loops, and file handling in a practical application. The Student Record Management System demonstrated how a simple Python program can store, retrieve, search, and delete records without requiring a database.
