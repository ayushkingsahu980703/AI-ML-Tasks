# Day 2 — Python Fundamentals

**Date:** 6 October 2026  
**Program:** AI/ML Internship

## Overview

Day 2 focused on Python programming fundamentals, including variables, data types, conditional statements, loops, and functions. These concepts were applied through two practical programs: a Student Grade Calculator and a Simple Calculator.

## Learning Objectives

- Understand Python variables and data types.
- Practice conditional statements using `if`, `elif`, and `else`.
- Implement iteration using `for` and `while` loops.
- Create reusable functions with parameters and return values.
- Apply Python fundamentals to build simple interactive programs.

## Tasks Completed

### 1. Python Fundamentals

Practiced the following concepts:

- **Variables and Data Types:** Working with `str`, `int`, `float`, and `bool`.
- **Conditional Statements:** Making decisions based on conditions.
- **Loops:** Repeating operations using `for` and `while`.
- **Functions:** Creating reusable functions for calculations and greetings.

### 2. Student Grade Calculator

Developed an interactive program that accepts a student's name and marks in five subjects:

- Mathematics
- Science
- Social Science
- English
- Computer

**Features:**
- Calculates total marks.
- Calculates the average percentage across five subjects.
- Assigns a grade based on the calculated percentage.
- Displays the student's result and pass/fail status.

The program uses conditional statements to determine the grade and final result.

### 3. Simple Calculator

Built a menu-driven calculator using separate Python functions.

**Operations supported:**
- Addition
- Subtraction
- Multiplication
- Division

**Features:**
- Accepts two numerical inputs.
- Executes the selected arithmetic operation.
- Uses functions to keep the operations modular and reusable.
- Handles division by zero.
- Displays an invalid-choice message for unsupported menu selections.

## Technologies Used

- **Python 3**
- **Jupyter Notebook**

## Key Learnings

- Using variables to store and manipulate different types of data.
- Applying conditional logic to control program execution.
- Using loops to repeat instructions efficiently.
- Writing modular code with reusable functions.
- Accepting user input and displaying formatted results.
- Implementing basic error handling for division by zero.

## Conclusion

Day 2 strengthened the foundation in Python programming through hands-on practice. The Student Grade Calculator applied conditional logic to a practical problem, while the Simple Calculator demonstrated how functions can organize arithmetic operations into reusable components.

These fundamentals provide a foundation for subsequent data analysis and machine learning tasks.
