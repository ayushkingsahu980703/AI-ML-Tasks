# Day 1 — Introduction to AI/ML

## Overview

Day 1 focused on understanding the AI/ML learning roadmap, exploring the core concepts of Artificial Intelligence, Machine Learning, Deep Learning, and Generative AI, and establishing the development workflow for the internship.

## Topics Covered

### 1. AI, Machine Learning, Deep Learning & Generative AI

- **Artificial Intelligence (AI):** The broader field of creating systems capable of performing tasks that typically require human intelligence.
- **Machine Learning (ML):** A subset of AI that learns patterns from data to make predictions or decisions.
- **Deep Learning (DL):** A subset of ML that uses multilayer neural networks to learn complex patterns.
- **Generative AI:** AI systems that generate new content, including text, images, audio, video, and code.

### 2. Types of Machine Learning

- **Supervised Learning:** Learning from labelled data.
- **Unsupervised Learning:** Discovering patterns in unlabelled data.
- **Reinforcement Learning:** Learning through interactions with an environment using rewards and penalties.

### 3. Deep Learning Fundamentals

Introduced neural network architecture and foundational concepts, including neurons, weights, biases, activation functions, loss functions, forward propagation, backpropagation, gradient descent, epochs, learning rates, and overfitting.

Common architectures covered included CNNs, RNNs, LSTMs, GRUs, and Transformers.
